# Topics

テーマ別の学習コードとメモを置きます。

各テーマは原則として次の構成にします。

```text
topic_name/
  README.md
  template.py
  00_01_example.py
  00_02_example.py
```

- `README.md`: 考え方、使いどころ、計算量
- `template.py`: そのテーマの最終テンプレート候補
- `NN_xx_name.py`: 問題文、自分の解答、模範解答、別解

問題ファイルは次の形にします。

```text
topic_name/
  00_01_basic_summary.py
  00_02_count_frequency.py
```

各問題ファイルの先頭に、問題文、入力形式、出力形式、例、学びをコメントで書きます。
コード部分には、自分の解答、整理した模範解答、別解を必要に応じて残します。
