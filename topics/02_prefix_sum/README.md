# 02_prefix_sum

## 目的

累積和を使い、連続する区間の和を高速に求められるようにする。

## 扱う内容

- 一次元累積和
- 0/1 配列の累積和
- 二次元累積和
- 差分配列、いもす法

## 判断基準

- 配列の値が変わらず、区間の和を何度も求めるなら累積和を考える
- 複数の区間へ同じ処理を行い、最後の結果だけが必要なら差分配列を考える
- 長方形領域の和を何度も求めるなら二次元累積和を考える

## 例題

1. `02_01_range_sum_queries.py` - 複数の区間和クエリ
2. `02_02_count_in_ranges.py` - 区間内の条件を満たす要素数
3. `02_03_fixed_length_max_sum.py` - 長さ K の連続部分列の最大和
4. `02_04_rectangle_sum.py` - 長方形領域の和
5. `02_05_range_addition.py` - 区間加算
6. `02_06_imos_2d.py` - 長方形領域への一括加算

## 完了条件

- 一次元累積和を自分で構築できる
- 半開区間 `[left, right)` の和を求められる
- 二次元累積和で長方形領域の和を求められる
- 差分配列を使って区間加算を処理できる
